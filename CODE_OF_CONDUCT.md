# Code of conduct

Applies to issues, pull requests and discussions in
[criptonautas](https://github.com/criptonautas).

- Discuss the work, not the person. Disagreeing is fine; insults, harassment and
  discrimination are not.
- Respect people's privacy. Do not publish anyone's personal data.
- No spam or promotion.

Maintainers may edit or remove content and block accounts that break these rules.
Report problems to dev@criptonautas.co.
